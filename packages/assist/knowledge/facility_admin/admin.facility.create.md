# Create a facility

Only an organization administrator can create a facility.

1. Open [administration](route:admin.home).
2. Under **Create a facility**, enter the name, its URL identifier (slug) and its time zone.
3. Press **Create facility**.

## Then

- Add services, then counters, and tick the services each counter serves.
- Invite staff from the facility's **Staff** tab.
- These screens cannot rename or remove a facility.
