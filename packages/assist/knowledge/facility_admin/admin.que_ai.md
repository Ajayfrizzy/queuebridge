# AI explanations in Ask Que

The facility **Overview** has an **Ask Que AI explanations** section. It is off by default.

- Turning it on needs a facility administrator to read the notice and agree.
- Opting in does not switch AI on by itself. The deployment must also have an approved AI provider. When none is set up, the section says so and Ask Que uses built-in help only.
- Built-in help works for every role without AI.
