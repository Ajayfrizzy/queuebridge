# USSD access (test mode)

USSD is in test mode here (sandbox): there is no real USSD code to dial, and no real mobile-network session takes place. The steps below show how it will work.

## Using the phone menu

- Enter the 6-digit facility code shown at the facility.
- Press 1 to join a queue: choose a service that is taking visitors and confirm. You get your ticket code and a 32-character recovery key. Write both down.
- Press 2 to check your ticket: enter your ticket code, then your recovery key.
- Press 3 to recover your ticket: with your code and key you see your current ticket. If you lost them, ask a member of staff.
- Press 9 to go back and 0 to end the session.

## Keep your key private

- A ticket code alone or a phone number alone never opens a ticket.
- If the session times out, dial again and start over. A repeated step never makes a second ticket.

## Without a phone menu

Ask staff for a walk-in ticket. Your ticket code is on the public board when you are called.
