# Text message alerts (test mode)

Text messages are in test mode here (sandbox): no real message reaches a phone, and every message is labelled as a test.

## What staff see

When a visitor who asked for a text message is called, the visitor alert panel at the counter shows a **Text message** line:

- **Text message not sent yet**
- **Test text message accepted (sandbox: nothing sent to a phone)**
- **Test receipt received (simulated: no real message)**
- **Text message not sent: daily limit reached**
- **Text message not sent (visitor stopped text messages)**

Accepted is not delivered. Only a receipt from the provider counts as delivered.

## Stopping text messages for a visitor

Press **Stop text messages** in that panel. The visitor's number is deleted at once and no further message is sent. The visitor can also do this on their ticket page.

## Remember

A text message never changes the ticket and never marks a visitor missed. Calling the ticket aloud and the public board remain the reliable way to reach the visitor.

## Who can do this

Reception, Counter operator, Supervisor, Facility administrator, Organization administrator.
