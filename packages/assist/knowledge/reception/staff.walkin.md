# Issue a walk-in ticket

1. Open the queue console. The queue must be open.
2. Press **Issue walk-in ticket**. No name or phone number is needed.
3. Tell the visitor the ticket code. They can scan the QR to follow the ticket on their own phone.
4. Let the visitor scan or copy the recovery key shown for them. It is shown once.

## If the connection drops

- If the result is uncertain, press **Finish issuing walk-in ticket**. It does not create a second ticket.
- On a registered device without a connection, the ticket is saved on this device with a temporary reference, not a ticket number. The visitor gets a real code when the server confirms it. Recovery is not available until then.

## Who can do this

Reception, Counter operator, Supervisor, Facility administrator, Organization administrator.
