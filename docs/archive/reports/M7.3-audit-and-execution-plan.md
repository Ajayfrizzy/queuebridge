## Reviewed execution order and dependencies

1. Record SHA, frozen lockfile, environment and dated full/production audits. Run existing DB, concurrency and channel suites on disposable PostgreSQL 16+. Preserve provider-neutral channel and single-coordinator architecture.
2. Enumerate registered public routes. Verify successful boundary request, 429, window recovery and independent callers. Assess legitimate health probes before choosing protection.
3. Rebuild, measure cold route JS/CSS and repeated Lighthouse LCP/CLS/TBT, derive regression gates and independently assess the absolute visitor target. Account separately for worker install, warm load and offline.
4. Preserve Chromium coverage. Add Firefox/WebKit mobile and desktop smoke for landing, sign-up entry, join, ticket and staff call. Publish real-device and assistive-technology observations separately.
5. Run full local regression, repeat migrations and db-validate.yml SQL assertions. Retain commands, SHA, logs, skips and failures. Hosted CI remains a merge gate.

pnpm install --frozen-lockfile

The owner decisions requested at review concerned the absolute visitor budget, monitor exposure, physical-device access, hosted CI capacity and RumptyCloud topology. Validate static SPA routing, response headers, Node API, continuous worker, PostgreSQL, secret isolation, migration and probe access, TLS, streaming and zero personal spending before any deployment approval.
