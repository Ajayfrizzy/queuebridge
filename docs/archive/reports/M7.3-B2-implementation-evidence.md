## Remaining budget and decision

Join and ticket each saved 36,011 B. A further 59,634 B must leave startup to meet the strict maximum of 99,999 B. Candidate source-map attribution using the B1 method measured independent gzip fragments for React DOM (54,794 B), Zod (26,866 B), router (14,365 B), QR encoding (9,485 B), ticket page (5,111 B) and recovery page (2,088 B). These fragments cannot be added as predicted savings. Propose lazy QR creation and visitor-route separation first, followed by a targeted audit of eagerly imported contract schemas. Preserve recovery fragment scrubbing, eager CSP-safe validation initialization, session and offline state. These additional boundaries need approval.

## Next optimization review

The production graph rebuild emitted 168 modules in index-DMLaJOgj.js. Both visitor URLs start with this entry and registerSW.js. React DOM, React Router, the route's own rendering and input handling, display preferences, announcements, session resolution, connectivity observation and the validators used by that interaction belong on its immediate path. Staff screens and the Ask Que panel already have asynchronous boundaries.

1. **QR rendering on demand.** TicketPage imports RecoveryKeyPanel, which imports lib/qr.ts and qrcode. Show QR already gates computation. Move the encoder import to the QR display action, checking all other eager QR callers. The encoder's 9,485 independently gzipped bytes give an order-of-magnitude estimate of roughly 9 KB of opportunity. Keep grouped text, copy, print and fragment scrubbing usable while the image loads. Preserve focus, avoid logging credentials and verify offline generation after worker installation.
2. **Other-route screens.** TicketPage (5,111 B), JoinPage (2,133 B) and RecoverPage (2,088 B) are statically reachable on every visitor entry. Independently defer recovery rendering or a sibling route. Join can avoid ticket rendering until transition; ticket must still download it on direct entry. Preserve synchronous fragment handling, focus and title updates, loading announcements and direct offline reopening. The estimates are kilobytes per unrelated route, with shared helpers reducing the potential saving.
3. **Push controls and contract imports.** PushAlertPanel accounts for 2,281 B and packages/contracts/dist/que.js for 2,475 B using the same attribution. Audit which imports require those schemas on join. Keep turn notification readiness and deterministic navigation available before deferring optional configuration UI. Zod's 26,866 B includes validation needed on the visitor path. Determine the removable subset experimentally under the existing CSP and schema regression tests.
4. React DOM (54,794 B) and React Router (14,365 B) are the largest rendering and routing dependencies. Replacing either, changing schema semantics or relocating session/offline authority would require separate architectural review. No measured candidate presently closes the entire 59,634 B gap. Re-run both cold journeys and the worker update/offline checks after each individually approved experiment.
