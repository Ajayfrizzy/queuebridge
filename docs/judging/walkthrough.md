# Judge walkthrough

Sign in with organization slug `judge-demo`. Passwords are supplied separately through the approved private judge channel. Use a separate browser profile for the anonymous visitor so the staff and visitor views can be watched side by side. All facility and ticket records used for this demonstration are fictional. [Staff sign-in](https://queuebridge.rumptycloud.app/login) · [Visitor entry for Willow Crossing Service Centre](https://queuebridge.rumptycloud.app/join/judge-demo/session-1)

| Role                       | Sign-in email                              | What to try                                                                                                                                    |
| -------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Organization administrator | org_admin@judge-demo.example.invalid       | Open Administration and select Willow Crossing. Inspect facilities and staff access.                                                           |
| Facility administrator     | facility_admin@judge-demo.example.invalid  | Inspect Registration and Consultation, desk capabilities, channel availability and the visitor join QR.                                        |
| Receptionist               | staff_reception@judge-demo.example.invalid | Open today's queue and issue a fictional walk-in ticket. Compare its public code with the visitor's web ticket.                                |
| Counter staff              | staff_counter@judge-demo.example.invalid   | Select an eligible desk, call next, start service and complete the called ticket. Watch the visitor or board when its specific code is called. |
| Supervisor                 | supervisor@judge-demo.example.invalid      | Inspect the ordering policy and priority explanation. Open Connectivity and recovery to inspect device and synchronization status.             |
| Auditor                    | auditor@judge-demo.example.invalid         | Open queue audit history, inspect the sequence and run the integrity check using read-only access.                                             |

1. Start as a visitor. Choose an open service, join and keep the recovery key privately. Follow the position and estimate. Try **Display and alerts**, keyboard navigation and Ask Que. Restore your ticket in another browser profile using its recovery flow.
2. Compare that experience with reception and counter operations above. The seed opens two queues with five tickets in total: two ordinary waiting, one priority waiting, one called and one completed. Welcome Desk and Consultation Desk are dedicated, while Relief Desk serves both services. The live state changes as judges use it. On a later operational day, an authorized operator can open today's queues normally.
3. For the outage walkthrough, arrange exclusive use of the designated coordinator with the operator. Load the queue online, disconnect only that browser, record a permitted operation, and observe its pending state. Reconnect, wait for reconciliation and compare the result with the supervisor and audit views. Keep that device signed in until pending work is accounted for. Judges can explore all other screens independently without changing coordinator ownership.
4. For a read-only walkthrough, use the auditor account and observe another evaluator's ticket progress. The public board uses ticket codes. Keep recovery links, credentials, private reasons and browser address bars out of shared recordings.
